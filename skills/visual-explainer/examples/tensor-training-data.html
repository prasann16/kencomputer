How text becomes an LLM’s training data

Text turns into numbers, and every position becomes a lesson: given what came before, guess the next token.

Stack B rows like this and you get a (B, T) tensor of integers: here T is 6, so one row holds 6 next token lessons.

1. Start with plain text from the training set.

2. The tokenizer cuts it into common chunks of characters.

3. Each token is swapped for its ID in a fixed vocabulary of 50,257.

4. A window of T = 6 IDs becomes the input row x.

5. The same window moved one to the right is the answer row y.
