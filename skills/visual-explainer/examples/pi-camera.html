Plug a camera into a Raspberry Pi

Raspberry Pi 4 and Camera Module 3. It takes a minute, and the only trick is which way the cable faces.

Then power on and run rpicam-hello. A live preview means it worked.

1. Unplug the USB C power. Never plug a camera into a running Pi.

2. Find the port marked CAMERA, between the HDMI ports and the audio jack.

3. Gently lift the latch. It slides up, it doesn’t come off.

4. Push the cable all the way in, silver contacts toward the HDMI ports.

5. Press the latch down to lock it.

6. Power on and run rpicam-hello. A live preview means it worked.
